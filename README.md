# 地下ダンジョン脱出ゲーム

武器を持たない初心者冒険者が、全10階層の地下ダンジョンから地上への生還を目指す、テキストアドベンチャーです。

## 遊び方
- `index.html` をブラウザで開くとプレイできます。
- 選択肢を選びながら、周囲の状況を観察して脱出を目指します。
- 現在の場面と到達済み階層のチェックポイントはブラウザのローカルストレージに自動保存されます。
- ゲームオーバー時は、最後に到達した階層の開始地点から再開できます。
- 「最初から」で確認ダイアログを表示し、保存データを消去して第十層からやり直せます。
- 外部ライブラリや画像は使用していません。

## 開発・検証
Node.js 20 以降で次のコマンドを実行します。

```sh
npm test
npm run check:syntax
```
