# 地下ダンジョン脱出ゲーム

武器を持たない初心者冒険者が、崩落で落とされた未知の地下から地上への生還を目指すテキストアドベンチャーです。

## 遊び方
- `index.html` をブラウザで開くとプレイできます。
- 選択肢を選びながら、周囲の状況を観察して脱出を目指します。
- 進行状況と探索履歴はブラウザのローカルストレージに保存されます。
- ゲームオーバー時はチェックポイントから再開できます。
- 「最初から」で保存データと探索履歴を削除できます。

## 開発・検証
Node.js 20 以降で次のコマンドを実行します。

```sh
npm install
npm test
npm run check:syntax
```

テストでは、シナリオデータの形式、すべての分岐先の存在、開始地点からの到達可能性、成功・失敗エンディング、階層表示とチェックポイントの前提を検証します。GitHub Actions でも Pull Request ごとに自動実行します。
